# 政見自動更新規則（排程任務每次執行都要照做）

目標：讓 `data/platforms.json` 裡每位候選人的「主要政見」標籤保持最新、可查證、對所有候選人一視同仁。

## 來源優先順序
1. **中選會**：選舉公報（約 11 月下旬上網）、公辦政見發表會（直轄市長 11/13–11/27）
2. **候選人本人／競選團隊**的官方網站、官方臉書、記者會發布的政見
3. **中立報導**：中央社、公視新聞網，其次為聯合新聞網、自由時報、ETtoday、TVBS、天下、遠見等主流媒體的**事實報導**
- 不採用：評論、社論、名嘴節目、內容農場、匿名爆料、對手陣營轉述的政見、民調文章

## 收錄標準
- 只收「候選人自己公開提出的**未來**施政主張」。現任者的過去政績不算政見。
- 每個標籤 **2～9 個中文字**，用中性的名詞或動詞片語描述內容本身（例：「免費營養午餐」）。不加形容詞，也不寫評價（例如不能寫「大膽」「空頭」）。
- 每人**最多 4 個**。有新政見時，保留最具體、篇幅最大的 4 項。
- 每個標籤都必須能在 `sources` 的某一篇文章裡找到；每位候選人最多 3 筆來源，優先放最新、最原始的那篇。
- 來源的 `title` 用自己的話寫成短摘要（不可照抄原標題超過 15 字）；`date` 是文章發布日（YYYY-MM-DD）。
- 查不到政見就不要硬寫：`tags` 留空，`status` 填「尚未正式發表競選政見」或「政見整理中」。
- **公平原則**：每次執行都要逐一檢查所有候選人（含小黨、無黨籍），不能只更新熱門候選人。

## 檔案格式
鍵值是「城市代碼/姓名」，姓名要和 Supabase `sc_candidates` 表完全一致。城市代碼：taipei、newtaipei、taoyuan、taichung、tainan、kaohsiung。
```json
"tainan/陳亭妃": {
  "tags": ["五大觀光軸", "成立青年局"],
  "status": null,
  "sources": [{ "publisher": "中央社", "date": "2026-09-01", "title": "陳亭妃提出五大觀光軸", "url": "https://..." }]
}
```
有任何變動時，把最上層的 `updatedAt` 改成當天日期。內容完全沒變就不要 commit。

## 法律提醒
- 本檔只寫政見，不寫民調、支持度、選情分析。
- 11/18 起至 11/28 投票截止前，網站任何地方都不能出現民調數字。
